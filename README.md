# 📊 Student Performance EDA

## 🎯 Overview
Exploratory Data Analysis on 1000 students
performance data using Python, Pandas & NumPy

## 📁 Dataset
- 1000 students, 8 features
- Source: Kaggle Students Performance Dataset

## 🔍 Key Findings
- Male students score higher in Math
- Female students score higher in Reading & Writing
- Test preparation improves scores by ~7.6 points
- Group E scored highest among all race groups
- Master's degree parents → highest scoring children
- Pass rate: 89.7% | Fail rate: 10.3%
- Most common grade: D

## 🛠️ Skills Used
- Pandas (DataFrame, GroupBy, Filter, Apply)
- NumPy (Statistical Analysis)
- Data Cleaning & EDA
